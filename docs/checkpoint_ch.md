## 已实现

- 插入引用之前，必须明确确认 Finder 原路径。
- 拖拽保护生效期间，外部文件拖拽不会降级为上传。
- 引用指向原文件，不改变 Session 权限。
- 面板位于 Goal 下方、输入框上方。
- 面板宽度与阅读区域一致。
- 文字采用与 Goal 正文一致的 13px 字号和 20px 行高。
- 插入成功后不显示提示。常驻标识继续显示。路径确认和错误处理功能保持不变。

## 文档维护

英文为默认语言。每份中文文档在同名英文文档的 `.md` 前添加 `_ch`。

行为变化时，同时更新两种语言。保持语言切换链接和同语言文档链接一致。公开文档不包含本机路径、job ID 或生成的报告。

文档提交前，运行[文档检查脚本](<../scripts/check-docs.mjs>)：

```sh
node scripts/check-docs.mjs
```
