## 拟定步骤

1. 获得对具体权限修改的批准。
2. 在独立审阅 clone 中固定当前候选。
3. 保留旧候选和报告。
4. 仅允许固定且已检查的探针命令，以及 clone 内的 Node 测试。
5. 保留对工作区、凭据和浏览器 profile 的文件访问限制。
6. 保留 sandbox 强制执行和网络限制。
7. 禁止委派和无关工具。
8. 运行一次隔离检查。
9. 仅在隔离检查通过后开始已批准的审阅。

只修改独立审阅 clone 的配置，不修改全局设置。不允许任意 Bash、`bypassPermissions` 或脱离 sandbox 的执行。

OS 探针必须实际执行，并证明隔离边界拒绝访问。跳过探针、命令层拒绝或未观察到连接，都不能提供充分证据。

如果检查失败，记录结果并停止。不要为了获得通过结果而削弱隔离边界。

本方案不授予执行权限。见[审阅状态](<review-status_ch.md>)。
